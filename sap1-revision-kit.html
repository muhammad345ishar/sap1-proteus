6-bit ring counter

FF1 preset to 1, FF2–FF6 cleared · Q6 → D1

Gated clock = CLK·HLT. A NOT gate inverts the HLT decoder line and an AND gate lets the clock through only while HLT = 0. Turn HLT on and the pulses stop reaching the ring.

Tri-state buffer

third state: Hi-Z, disconnected from the wire

bufif1: C = 1 connects, C = 0 gives Hi-Z. bufif0 is the opposite. The 74LS126 is a quad tri-state buffer with active-high control, so 8 bits need two chips (used on the accumulator, controlled by EA).

74LS173 · 4-bit register with tri-state outputs

Output pins

Load: G1 and G2 both low, data taken on the rising edge. Outputs: M and N both low, else Hi-Z. CLR high clears all four bits at once.

SAP-1 trick: tie G1 and G2 together and drive them with the active-low load signal (Lm, LI, LA, LB, Lo). Ground M and N when the register should always show its value (MAR, B, A to the adder, output register); drive them only when the register writes to the bus (IR address nibble).

Standard pin pairs: Q0/D0 on pins 3/14, Q1/D1 on 4/13, Q2/D2 on 5/12, Q3/D3 on 6/11. M = 1, N = 2, CLK = 7, G1 = 9, G2 = 10, CLR = 15. The handwritten sketch orders Q/D differently; check the datasheet before wiring.

8-bit adder/subtractor

two 7483 + two 74LS86 (XOR) + tri-state output stage on Eu
Su

A − B = A + B̅ + 1. Each B bit goes through an XOR with Su. Su = 0 passes B unchanged with carry-in 0 (add). Su = 1 inverts B and feeds carry-in C0 = 1 (subtract).

The adder stores nothing. Its output follows A and B all the time, and A only takes the result when Eu is on and LA = 0 (T6). Range in 2's complement: −128 to +127.

The box labelled "OB/2" in the handwritten page is the second half of the XOR row (B7–B4), drawn as one box.

74LS189 RAM and program loading

16 × 4 per chip, two chips give 16 × 8 · outputs are inverted
CS̅ WE̅

Outputs are complemented. To read back the true word, enter its complement on the data switches (or add inverters). The notes' example: LDA 1010 → 0000 1010 → enter 1111 0101.

Run mode: address from the MAR, WE̅ = 1, and the controller pulls CS̅ low only in the read steps (T3, T5), so the RAM stays Hi-Z otherwise.

Load mode: address from four switches SW1–SW4, data from the data switches, CS̅ = 0, and a push switch pulses WE̅ low to latch the word. The RUN/PROGRAM switch picks the address source.

Common mistakes

  • Incrementing the PC in T1. The address goes to the MAR in T1; Cp is its own step T2.
  • Two senders on the W-bus in the same step. Their outputs fight.
  • Forgetting that Lm, CE, LI, LA, LB, Lo are active low, so a NOR, NAND or NOT sits in front of them.
  • Using Su = 1 for ADD. Su is 0 for ADD and 1 only in T6 of SUB.
  • Writing the true word into a 74LS189 and reading back its complement.
  • Decoding LEN from IRH in the variable-length machine. IRH loads at the end of T3, so LEN is read from the bus.

Quick revision

  • Controller–sequencer = instruction decoder + ring counter. Signal = OR of (step AND instruction).
  • Fetch: T1 Ep, Lm · T2 Cp · T3 CE, LI.
  • HLT stops the clock with one NOT and one AND on the clock line.
  • 74LS173: load with G1G2 low, output with M, N low, clear with CLR high.
  • A − B = A + B̅ + 1: XOR with Su, Su into carry-in.
  • 74LS189: 16 × 4, outputs complemented, WE̅ = 0 writes.
  • Modified SAP-1: 180 instructions → 8-bit opcode → 2-byte instruction, 256 bytes, 9 states.
  • n-byte: 3n fetch + 3 execute = 3n + 3 states.
  • Variable length: LEN = OUT + HLT; D4 = T3·LEN̅, D7 = T6 + T3·LEN; 6 or 9 steps.
