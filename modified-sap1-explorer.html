HLT is counted up to and including the state where the gated clock stops (T3n+1). The notes count SAP-1 HLT as 3 useful steps, which leaves that last state out.

Why two bytes?

opcode bits from the instruction count

What stays the same: the accumulator, B register, adder/subtractor, output register and the 8-bit W-bus. Only the address-and-instruction side gets wider, and the controller gets more timing steps.

Seven design steps

the recipe from Chapter 6
  1. Fix the format. How many bytes, and which are opcode, address or data.
  2. Size the machine. Address bits set memory, PC and MAR width; opcode bits set the decoder.
  3. Count the states (3n + 3) and choose a ring counter or a binary counter + decoder.
  4. Write the control table: which signals are on in each Tk for each instruction.
  5. Read off one equation per signal: OR of (step AND instruction).
  6. Handle short instructions: skip to the first execute step, or pad them.
  7. Test by tracing a small program against the table.
Example program from the notes: LDA, ADD, SUB, OUT, HLT on data 9, 5, 3, so A = 9 + 5 − 3 = 11 (0BH). Opcodes: LDA 00, ADD 01, SUB 02, OUT 03, HLT FF (SAP-1 uses the 4-bit codes 0, 1, 2, 3, F). Data addresses: SAP-1 8–A, 2-byte 10–12H, 3-byte 0100–0102H, 4-byte 000100–000102H.
