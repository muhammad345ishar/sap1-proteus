(b) −11 as a 5-bit signed 2's-complement number [2]

2's complement of a number = invert every bit (1's complement), then add 1. That works because $N + \overline{N} = 2^n - 1$, so $\overline{N} + 1 = 2^n - N$, which is how $-N$ is stored in $n$ bits.

StepBits
+11 in 5 bits0 1 0 1 1
Invert (1's complement)1 0 1 0 0
Add 11 0 1 0 1
−11 = 10101₂. Check: $-16 + 4 + 1 = -11$ (the MSB weighs $-2^4$).

(c) Half-step stepper motor: clock, counter and coil timing, and coil equations [10]

Half-step mode alternates between one coil and two adjacent coils energised, giving 8 steps per electrical cycle (A, AB, B, BC, C, CD, D, DA). A 3-bit binary counter $Q_2Q_1Q_0$ (0 → 7) clocks through the steps; a decoder (the equations below) turns each count into the coil pattern.

Each coil is a sum of the minterms where it is 1, then simplified (K-map / Boolean algebra):

$$A = \sum m(0,1,7) = \overline{Q_2}\,\overline{Q_1} + Q_2Q_1Q_0$$ $$B = \sum m(1,2,3) = \overline{Q_2}\,(Q_1 + Q_0)$$ $$C = \sum m(3,4,5) = Q_2\overline{Q_1} + \overline{Q_2}\,Q_1Q_0$$ $$D = \sum m(5,6,7) = Q_2\,(Q_1 + Q_0)$$

Reversing the motor = count down instead of up (same equations).

(d) NOT, AND and OR using only NAND gates [2]

NOT: tie both NAND inputs together, $\overline{A\cdot A} = \overline{A}$. AND: NAND then a NAND-inverter, $\overline{\overline{AB}} = AB$. OR: invert each input then NAND (De Morgan), $\overline{\overline{A}\,\overline{B}} = A + B$.

(b) HDL module for the half subtractor [6]

Half subtractor: $D = A \oplus B$, $B_{out} = \overline{A}B$.

// Verilog - dataflow (equation) description
module half_subtractor (
    input  wire A, B,
    output wire D, Bout
);
    assign D    = A ^ B;     // difference
    assign Bout = ~A & B;    // borrow
endmodule

// Gate-level version of the same circuit
module half_subtractor_gates (input A, B, output D, Bout);
    wire An;
    xor g1 (D, A, B);
    not g2 (An, A);
    and g3 (Bout, An, B);
endmodule

(c) JK flip-flop sequence generator for the half-step controller, with reset to 1000 [20]

Use four JK flip-flops whose outputs drive coils A, B, C, D directly, so the state is the coil pattern. Required sequence:

1000 → 1100 → 0100 → 0110 → 0010 → 0011 → 0001 → 1001 → (back to 1000)

JK excitation table (what J, K must be for each wanted change; X = don't care):

Q → Q⁺JK
0 → 00X
0 → 11X
1 → 0X1
1 → 1X0

It comes from the JK characteristic equation $Q^+ = J\overline{Q} + \overline{K}Q$: if Q = 0 only J matters; if Q = 1 only K matters.

Simplify each column (4-variable K-maps with the 8 unused states as X). For example, $J_A$ is 1 only at 0001 and 0 at 0100, 0110, 0010, 0011, so $\overline{C}D$ covers the 1 without touching any 0; $K_A$ is 1 at 1100 and 0 at 1000, 1001, so $K_A = B$. The others follow the same way:

$$J_A = \overline{C}D,\quad K_A = B \qquad J_B = A\overline{D},\quad K_B = C$$ $$J_C = \overline{A}B,\quad K_C = D \qquad J_D = \overline{B}C,\quad K_D = A$$ Neat pattern: each coil turns on when the coil before it is on and the one behind that is off, and turns off once the next coil is on.

Reset to 1000: PRESET′ and CLEAR′ are active-low asynchronous inputs (they act immediately, ignoring the clock). A push-button pulls the RST′ line low (10 kΩ pull-up keeps it high otherwise). RST′ goes to PRESET′ of FF-A (A = 1) and to CLEAR′ of FF-B, FF-C, FF-D (B = C = D = 0). The unused PRE′/CLR′ pins are tied to +5 V.

Why the reset is essential: simulating all 16 states shows 0000 is a lock-up state (all J = 0, so it never leaves), and 0101, 1010, 1111 fall into it. The other unused states (0111, 1011, 1101, 1110) rejoin the sequence in one clock. So at power-up the reset switch must be pressed to start from 1000.

(a) PWM generator block diagram [15]

A free-running counter sets the base frequency; one register holds the period, another the on-time. A comparator resets the counter at the end of each period, and a second comparator keeps the output high while the count is below the duty value.

The counter runs $0 \to P$, i.e. $P+1$ clocks per cycle: $$T_{PWM} = (P+1)\,T_{clk},\quad t_{on} = D_{ty}\,T_{clk},\quad t_{off} = (P+1-D_{ty})\,T_{clk},\quad \text{duty} = \frac{D_{ty}}{P+1}$$

The output D-FF re-times LT on the clock so comparator glitches never reach the output. For glitch-free duty changes, write DUTY into a shadow register that is copied on TC.
