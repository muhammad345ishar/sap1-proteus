SAP-1 Lab

You can be the controller. Click the violet control pins on the blocks to switch signals on, then press Clock: whatever chip is enabled puts its byte on the bus, and whatever register is loading grabs it. Switch to Automatic to see the real controller-sequencer (U19, U20, U21) flip the same pins for you. Change memory, A, or B to see how different inputs give different outputs.

The machine

Controller-sequencer

Where it is in your Proteus schematic

1 · Step counter U19 (T-state)

2 · ROM address = opcode (from U5) + step (from U19)

3 · U20 / U21 look up the control word

After T6, U24 (NAND of S1, S2) and U22:B clear U19 back to T1. On HLT, U20 drives nHLT low and U22:A blocks the clock, so the whole machine freezes.

Adder / subtractor, bit by bit

U12–U13 (XOR) and U14–U15 (74LS283). It always shows A + B. When Su = 1, each XOR flips its B bit and the carry-in becomes 1. Flipping every bit and adding 1 is the two's complement, so the same adder now gives A − B.

Memory · putting data in

U4 is a ROM, so data is put in before the machine runs (Malvino used switches; you use the .BIN file). Click a row to change it. The machine resets to use the new program, and the Python block below is exactly what to paste into make_roms.py to put the same data into Proteus.
