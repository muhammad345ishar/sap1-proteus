SAP-1 in Proteus

Malvino's Simple-As-Possible computer, built from 74LS chips and simulated in Proteus 8. Interactive pages for learning how its bits move, plus the project files and ROM images.

Interactive pages

  1. SHT 01SAP-1 Bit Flow Watch each byte travel the W bus between registers, one T-state at a time.
  2. SHT 02SAP-1 Chip Field Guide Every non-gate IC with its real DIP pinout, pin-by-pin behaviour and a mini simulator.
  3. SHT 03SAP-1 IC Workbench Each chip on its own test bench, with switches, a clock button, probes and its internal logic coloured live.
  4. SHT 04SAP-1 Lab Be the controller: switch the control pins yourself and clock data around, or let the real sequencer run it.
  5. SHT 05SAP-1 Controller Sequencer Opcode decoder, step counter and the AND–OR–NOT matrix that makes all 12 control signals, gate by gate.
  6. SHT 06Modified SAP-1 Explorer Step the 1-, 2-, 3- and 4-byte machines: 3n + 3 states, address path, control matrix, equations and a full program trace.
  7. SHT 07Variable-Length SAP-1 The LEN signal and the T3 → T7 skip in the 9-bit ring counter, with live gates, state diagram, timing and Verilog.
  8. SHT 08SAP-1 Revision Kit Bus rule, ring counter and HLT gate, tri-states, 74LS173, adder/subtractor and 74LS189 loading, plus revision tables and a quiz.

Project files

  • proteus/SAP1.pdsprj — the microcoded SAP-1 (control ROMs)
  • proteus/SAP1_Controller_wired.pdsprj — hard-wired controller version
  • PROGRAM_ROM.BIN, CONTROL_ROM1/2.BIN — ROM images, generated by make_roms.py
  • SAP1_PROTEUS_GUIDE.md, HARDWIRED_CONTROLLER_GUIDE.md — build guides
